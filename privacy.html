Privacy Policy — Decoded Past Uploader

Last updated: November 5, 2026

YouTube API Services

Decoded Past Uploader uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Who uses this tool

This is an internal tool used only by the operator of the Decoded Past channel. It has no public users and no accounts of its own.

What data is accessed

  • The identifier and title of the operator's own YouTube channel, used to confirm that uploads go to the correct channel.
  • The processing and privacy status of videos the tool has uploaded.
  • Google sign-in authorization tokens for the operator's own account.

How data is used and stored

The data is used only to upload the channel's own videos and to confirm the result. The authorization token is stored in a local file on the computer that runs the tool. No YouTube data is sold, shared with third parties, used for advertising or used for analytics. No cookies or tracking technologies are used by the tool or by this website.

Deletion and revoking access

Access can be revoked at any time on the Google security settings page. Deleting the local token file removes the stored authorization. Stored data is deleted within 7 days of a deletion request or of access being revoked.
